Supported browsers and devices

Porthole runs a full Tailscale client inside the page, so it needs a fairly recent browser. This page separates what has been tested from what should work on paper and what cannot work.

What sets the minimum versions

Two layers decide whether a browser can run Porthole. The Tailscale client sets a floor that we cannot lower. Porthole's own code sets a slightly higher one that we could lower with more work.

Porthole also needs to be opened over HTTPS, and the network must allow WebSocket connections to Tailscale. The client is a 30 MB download and used 18 MB of WebAssembly memory at the sign-in screen in all three tested browsers.

How this was checked

  • Tested browsers ran two automated tests on a Mac. The first starts the Tailscale client and asks Tailscale for a sign-in address. The second runs 47 checks of page loading, redirects, forms, cookies, WebSockets, streaming and tab takeover against stand-in sites.
  • Browsing a real tailnet end to end has so far been checked by hand, not in every browser listed as tested.
  • Minimum versions come from MDN's browser compatibility data for each feature the code uses, and from scanning the client's WebAssembly for the instructions it contains.
  • TV engine versions come from the Samsung and LG developer sites. Those tables describe each TV's web engine. Samsung's does not say whether the built-in browser app matches it.
